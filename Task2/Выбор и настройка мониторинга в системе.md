## Мониторинг
# Мотивация
Метрики представляют собой агрегированные или одиночные данные о том, как себя чувствуют сервисы.
Это стандарт индустрии, который необходим для глубоково понимания и выявления инцидентов. Без него мы не сможем оперативно обнаруживать и исправлять проблемы в системе.

Так как наша система имеет распеределенну структуру, каждый компонент развертки нагружен по-своему и им необходим уникальный набор данных для отслеживания.

# Выбор подхода к мониторингу
* Онлайн-магазин — RED.
* CRM — RED.
* MES — Четыре золотых сигнала.

# Метрики для отслеживания 
* Number of dead-letter-exchange letters in RabbitMQ
* Number of message in flight in RabbitMQ
* Number of requests (RPS) for internet shop API
* Number of requests (RPS) for CRM API
* Number of requests (RPS) for MES API
* CPU % for shop API
* CPU % for CRM API
* CPU % for MES API
* RAM % for shop API
* RAM % for CRM API
* RAM % for MES API
* Disk % for shop API
* Disk % for CRM API
* Disk % for MES API
* Memory Utilisation for shop db instance
* Memory Utilisation for MES db instance
* Number of connections for shop db instance
* Number of connections for MES db instance
* Response time (latency) for shop API
* Response time (latency) for CRM API
* Response time (latency) for MES API
* Size of S3 storage
* Size of shop db instance
* Size of MES db instance
* Number of HTTP 400/500 for shop API
* Number of HTTP 400/500 for CRM API
* Number of HTTP 400/500 for MES API
* Number of HTTP 400/500 for shop API
* Number of simultanious sessions for shop API
* Number of simultanious sessions for CRM API
* Number of simultanious sessions for MES API

# План действий
В первом квартале для сбора метрик применим инструмент Prometheus, который имеет встроенный TSDB. 
Для этого нам потребуется docker образ Prometheus. Настроить конфигурации static_configs для каждого инстанса, за которым мы будем наблюдать: 
* RabbitMQ 
* S3 
* db-mes
* db-shop
* shop API
* CRM API
* MES API

Во втором квартале необходимо подключить визуализатор метрик Grafana для построения дашбордов, что улучшит читаемость метрик из Prometheus.
