## Анализ, идентификация проблем и решений, планирование
Система состоит из трёх приложений:
* Онлайн-магазин — написан на Vue и Java Spring Boot.
* CRM — SPA-приложение, фронтенд написан на Vue, бэкенд — на Java Spring Boot.
* MES — SPA-приложение, фронтенд написан на React, бэкенд — на C#.

# Проблемы компании
Из-за роста бизнеса происходит линейное увеличение нагрузки на систему, после чего начались свои в работе и жалобы со стороны клиентов.

Каждое приложение имеет телько один инстанс и при запуске не были учтены механизмы масштабирования.

Не устранив проблему с производительностью, руководство приняло решение дальше увеличить охваты бизнеса и открыть API MES, что усугубило проблему.

Основная проблема в том, что клиентам не могут доставить заказ из-за недостатков системы. MES настолько загружена, что пришлось урезать функциональность прорисовки дашбордов, по которым операторы могли добросовестно отправлять заказы в срок.

# Инициативы
В ближайшие два квартала необходимо:
* Внедрить кеширование на чтение для БД MES
* Внедрить мониторинг для отслеживания основных метрик 
* Внедрить трассировку для облегчания поиска проблемного сериса в распределенной системе
* Внедрить логирование для более оперативного и качественного анализа инцидентов
* Увеличить ресурсы ЦОД для вертикального и горизонтального масштабирования
* Настроить инфраструктуру для горизонтального масштабирования (Discovery, Balancer, Circle Breaker)
